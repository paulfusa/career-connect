# Team-Generated User Stories and Features

These user stories and features came from our own team members, after we reviewed the AI-generated stories. They were **not** suggested by AI. The AI-generated stories were noted down in each member's `AI_Log/` folder.

## Team member-Generated User Stories

### US-03: Clear Application Outcome Message (#8)

**Proposed by:** Mohamad Alosta

**Story:** As a job seeker, I want a clear offer or rejection message with the reasons, so I am not left without an answer.

**Why:** Recruiters must explain their decision giving reasons without the system providing any prompts, and get reminders for unanswered applications. This prevents the "ghosting" phenomenon practiced by companies. 


### US-05: Browse and View Job Offers (#10)

**Proposed by:** Mohamad Alosta

**Story:** As a job seeker, I want to browse jobs, see if they are open, and see their acceptance rate, so I can decide where to apply.

**Why:** The acceptance rate helps job seekers choose where their time is best spent and if they truly have a chance to work in their dream companies.


### US-06: Submit Feature Suggestion (#11)

**Proposed by:** Mohamad Alosta

**Story:** As a user, I want to suggest features and explain how they would help me, so the team can improve the platform.

**Why:** We cannot assume every user need, hence having them share their thoughts and ideas might improve the hiring process.


## Required Features (to be confirmed)
- **Generative AI feature:** AI-assisted resume feedback. It suggests how to improve a resume's clarity and relevance.
- **Original feature:** Clear application outcome message (US-03), where recruiters must explain every decision and applicants aren't ghosted.
